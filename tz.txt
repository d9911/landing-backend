Задача
Сделать небольшой лендинг-презентацию себя как разработчика.
Нам важно увидеть:
как вы пишете frontend
как работаете с API
как используете AI-инструменты
как организуете проект

Что должно быть
1. Информация о себе
стек
опыт
направления разработки
2. Как вы работаете
подход к задачам
как используете AI в работе
3. Кейсы / опыт
реальные или учебные проекты
что делали лично
4. Контакты

Форма обратной связи
На сайте должна быть форма:
Поля:
имя
телефон
email
комментарий
После отправки:
письмо должно приходить владельцу сайта
копия письма должна приходить пользователю
должна быть обработка ошибок и успешной отправки

Требования к реализации
Использовать:
JS/TS
HTML
SCSS/CSS
Важно:
адаптивность
аккуратная структура проекта
валидная верстка
обработка ошибок
loading/success/error состояния

API часть
Нужно реализовать минимальную backend/API часть для формы.
Можно использовать:
PHP
Symfony
Node.js
serverless function
любой аналогичный вариант

Дополнительно
Будет плюсом, если покажете любую AI-интеграцию.
Например:
генерацию текста
AI helper
AI summary
интеграцию с AI API
OpenAI API
OpenClaw/tool calling сценарий
Сложность не важна.
Важно показать подход.

Важно
Красивая верстка без рабочей логики -не считается выполненным тестовым.
Рабочая форма без нормального frontend - тоже не считается выполненным.
Нам важно увидеть полный цикл:
frontend → API → обработка ошибок → результат.
