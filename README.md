# 🚀 Full-Cycle Developer Portfolio | Den Gu

Промышленный адаптивный лендинг-презентация, разработанный в строгом соответствии с дизайн-системой **Mistral AI**. Проект демонстрирует полный цикл разработки (Frontend + Backend), архитектурный подход к организации кода и интеграцию ИИ-инструментов.

## 🎯 Выполнение требований ТЗ

Проект полностью закрывает все требования тестового задания:

- **Информация о разработчике:** Стек, опыт, подходы к разработке (FSD, Clean Architecture).
- **Frontend:** Нативный стек (HTML5/CSS3/JS), адаптивная вёрстка без тяжелых фреймворков для максимального Performance, валидация данных.
- **Backend:** Node.js + Express API для обработки формы.
- **Полный цикл логики формы:** Валидация $\rightarrow$ Отправка (Loading) $\rightarrow$ SMTP Транзакция владельцу $\rightarrow$ SMTP Транзакция пользователю $\rightarrow$ Обработка ошибок (Error/Graceful Degradation) $\rightarrow$ Очистка формы (Success).
- **AI-Интеграция:** Встроенный интерактивный дашборд с использованием `Web Speech API` для транскрибации речи и её локального анализа (эмуляция AI-ассистента РОП).

## 🛠 Технологический стек и Архитектура

### Frontend (FSD-lite)

- **Core:** HTML5, CSS3 (Custom Properties, Grid/Flexbox), Native JavaScript (ES6+).
- **Интеграции:** `Web Speech API` для распознавания голоса в реальном времени.
- **Стилизация:** БЭМ-нейминг, модульная структура стилей, Pixel-perfect подход.

### Backend (Clean Architecture / DDD-lite)

- **Core:** Node.js, Express (v5.x).
- **Транспорт:** `nodemailer` для транзакционной почты.
- **Инфраструктура:** Разделение на слои (App, Features, Shared, Infrastructure, Routes). Поддержка `.env` конфигураций.

## 🚀 Как запустить проект локально

Проект оснащен `Makefile` для быстрого старта всей экосистемы в один клик.

### Требования

- Node.js (v18+)
- Yarn или npm

### Быстрый старт (Fullstack)

1. Склонируйте репозиторий и перейдите в папку проекта.
2. Выполните команду для установки зависимостей и параллельного запуска API и Frontend:

```bash
  make dev
```

_Команда автоматически создаст дефолтный файл `.env` для бэкенда, установит пакеты и поднимет оба сервера._

### Ручной запуск бэкенда

Если вы не используете `make`:

```bash
cd backend
npm install
cp .env.example .env # Укажите ваши SMTP данные
npm run dev
```

### Ручной запуск фронтенда

```bash
cd frontend
npm install
npm run dev

```

## 🤖 Использование AI-инструментов (Human-in-the-Loop)

Проект разрабатывался в тесной синергии с ИИ-ассистентами (**Claude 3.5 Sonnet** и **gemini**).

### Что было делегировано ИИ:

- Генерация адаптивной структуры CSS-гридов для секций "Опыт" и "Подход".
- Написание boilerplate-кода для SMTP-транспорта (Nodemailer) и HTML-разметки транзакционных писем.
- Первичная структура JavaScript-классов для работы с Web Speech API.

### Что исправлялось и проектировалось вручную (Инженерная работа):

- **Graceful Degradation для SMTP:** Бесплатный тариф Mailtrap (testing) блокирует отправку писем при превышении лимита 5 писем/сек (Ошибка 550). ИИ предложил `Promise.all`, что приводило к падению сервера. Логика была вручную переписана на последовательный `await` с искусственной задержкой и изолированным `try-catch` для второго письма. Теперь при лимитах сервера основное письмо доставляется, а пользователь получает красивое предупреждение (оранжевый статус), а не ошибку 500.
- **Изоляция типов и API:** Решение конфликтов имен Web Speech API с глобальными объектами DOM (доработка префиксов).
- **Express 5.x Middleware:** Переписывание устаревшего синтаксиса обработки ошибок, предложенного ИИ, под современные стандарты Express (явный возврат `.json()`).
- **Рефакторинг архитектуры:** Выделение монолитного кода в модульную структуру (разделение CSS, JS, HTML) для подготовки фронтенда под FSD, а бэкенда под Clean Architecture.
