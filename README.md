# Full-Cycle Developer Portfolio Landing Page

Промышленный адаптивный лендинг-презентация разработчика, разработанный в строгом соответствии с дизайн-системой **Mistral AI** и методологией **Feature-Sliced Design (FSD)**.

## 🛠 Использованный технологический стек

- **Frontend:** HTML5 (Семантическая вёрстка), CSS3 (Переменные, CSS Grid/Flexbox), Native JavaScript (ES6+), Интеграция с браузерным речевым API (**Web Speech API**).
- **Backend:** Node.js, Express (v5.x), пакет `nodemailer` для обработки транзакционной почты через пулы SMTP.

## 🚀 Инструкция по локальному запуску системы

### 1. Настройка и запуск бэкенда

Перейдите в директорию бэкенда и установите необходимые Node-модули:

```bash
cd backend
npm install
```

Создайте локальный файл конфигурации переменных окружения `.env` в корне каталога `backend/`:

```env
PORT=3001
OWNER_EMAIL=d.99113@gmail.com
SMTP_HOST=smtp.mailtrap.io
SMTP_PORT=2525
SMTP_USER=указать_ваш_smtp_user
SMTP_PASS=указать_ваш_smtp_password
SMTP_SECURE=false
```

Запустите бэкенд-сервер в dev-режиме:

```bash
npm start

```

### 2. Запуск фронтенда

Фронтенд написан на чистом нативном стеке для обеспечения максимального соответствия Core Web Vitals и мгновенного рендеринга страниц. Достаточно развернуть локальный сервер из папки `frontend/` с помощью расширения **Live Server** в VS Code или запустить глобальную утилиту:

```bash
npx serve .

```

## 📨 Архитектурная реализация формы (Полный цикл по ТЗ)

1. **Frontend Валидация:** Форма полностью контролируется JavaScript. На лету происходит проверка заполнения полей и валидация формата Email регулярными выражениями.
2. **UX-состояния:** При клике на кнопку отправки активируется состояние `isLoading` — кнопка блокируется во избежание повторных race-condition запросов, текст меняется на системный лоадер. При ответе сервера 200 — включается состояние `isSuccess` (зелёный баннер, очистка полей). При сбое сети или ошибках сервера — включается состояние `isError` (изолированный красный баннер).
3. **Backend API Handler:** Сервер на Node.js принимает `POST /api/feedback`, санирует данные и с помощью пула `Promise.all` инициирует две параллельные SMTP-транзакции: отправку детализированной карточки лида владельцу сайта и отправку официального авто-ответа с копией комментария на почту пользователю.

## 🤖 Использование AI-инструментов (Human-in-the-Loop)

Разработка велась в синергии с ИИ-ассистентами **Claude 3.5 Sonnet** и **Cursor** для ускорения рутинного кодинга.

- **Что делалось с помощью ИИ:**
- Генерация адаптивной структуры CSS-гридов для карточек опыта и стека.
- Построение разметки транзакционных писем для Nodemailer с поддержкой кросс-клиентских стилей.

- **Что пришлось исправлять вручную:**
- **Обработка Express Middleware:** ИИ написал устаревший синтаксис обработки ошибок для Express 4, который приводил к OOM-зависанию потока при пустом body. Код был переписан под особенности архитектуры Express 5 с явным вызовом `.json()`.
- **Конфликты имен Web Speech API:** При инициализации распознавания речи ИИ сгенерировал кастомные интерфейсы, пересекающиеся с глобальными типами DOM-библиотеки браузера. Ошибка исправлена вручную путем изоляции типов через уникальный префикс `ISpeechRecognitionEvent`.
