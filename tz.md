## Add PM2-based production runtime and Dockerize full application
Цель:
Добавить альтернативный production-рантайм через PM2 (без удаления текущего Makefile-подхода) и собрать frontend + backend в единое Docker-приложение.

📌 Требования
1. PM2 интеграция (backend)
Добавить конфигурацию PM2 (ecosystem.config.js)
Запуск backend через PM2 в production режиме
Поддержка:
restart при падении
логирование
возможность масштабирования (cluster mode — опционально)

👉 Важно:
Makefile-скрипты остаются и продолжают работать

2. Унификация запуска

Добавить альтернативный способ запуска:

через make (как сейчас) ✅
через pm2 ✅
3. Dockerизация

Собрать проект как единое приложение:

frontend билдится (Vite → static)
backend раздаёт frontend (или через nginx — опционально)
один контейнер = одно приложение
📦 Ожидаемый результат
Приложение запускается одной командой:
docker build -t app .
docker run -p 3000:3000 app

или через docker-compose (если выберешь его)

🧠 Архитектурные решения
PM2 используется как production process manager
Frontend собирается в /dist
Backend обслуживает статику + API
Конфигурация через .env
